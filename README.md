# ベジログ (VegeLog)

大学生の野菜摂取量を増やすことを目的とした、血管年齢計測と食事記録を組み合わせたWebアプリです。サーバー不要の単一HTMLファイルとして動作し、GitHub PagesやNetlifyなどの静的ホスティングにそのまま公開できます。

## 概要

被験者ID・血管年齢・ベジチェック値を登録すると、実年齢との差から「今の生活習慣を見直すきっかけ」を提示し、日々の野菜摂取を記録する習慣づけをサポートします。研究・実証実験のツールとしての利用を想定した被験者ID管理の仕組みを残しつつ、誰でも使える食事記録アプリとしても機能します。

## 主な機能

- **血管年齢の記録**：初回計測に加え、2回目以降の計測結果も蓄積し、推移を確認できます。
- **食事記録**：学食メニューからの選択、写真からのAI野菜量判定（Claude Vision API）、よく使う量のワンタップ手動記録の3通りに対応しています。
- **週間トレンド表示**：直近7日間の野菜摂取量をグラフで確認できます。
- **記録の編集・削除**：入力ミスがあった記録は、あとから品名・グラム数の修正や削除ができます。
- **LINE通知連携**：Google Apps Scriptで動く通知ボットと連携し、記録忘れリマインダー・学食のお知らせ・血管年齢の想起リマインダーをLINEで受け取れます（任意機能）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `vegelog.html` | アプリ本体。ブラウザで開くだけで動作します。 |
| `vegelog-line-bot.gs.txt` | LINE通知ボット用のGoogle Apps Scriptコード。 |
| `LINE連携セットアップ手順.md` | LINE公式アカウントの作成からGASデプロイまでの手順書。 |

## 使い方

### ローカルで使う

`vegelog.html` をダブルクリックするか、ブラウザにドラッグ＆ドロップして開くだけで利用できます。インストールや環境構築は不要です。

### 公開する（GitHub Pagesの場合）

1. このリポジトリをGitHubにプッシュします。
2. リポジトリの **Settings → Pages** を開き、公開元のブランチ（例: `main`）とルートフォルダを選択して保存します。
3. しばらくすると `https://ユーザー名.github.io/リポジトリ名/vegelog.html` のようなURLが発行され、そこからアプリにアクセスできます。

Netlify DropやCloudflare Pagesなど他の静的ホスティングでも、`vegelog.html` をアップロードするだけで同様に公開できます。

## 写真AI判定について（任意設定）

写真から野菜の種類・量を推定する機能には、[Anthropic Console](https://platform.claude.com/settings/keys) で発行したAPIキーが必要です。アプリの「設定」タブにキーを入力すると利用できます。キーはブラウザ内（localStorage）にのみ保存され、外部には送信されません。

> この方式はAPIキーがブラウザ上で扱われるため、個人利用・動作確認目的での利用を想定しています。不特定多数に配布する用途では、キーを秘匿するためのバックエンドの導入を検討してください。

## LINE通知連携について（任意設定）

記録忘れリマインダーなどをLINEで受け取りたい場合は、`LINE連携セットアップ手順.md` の手順に従ってLINE公式アカウントとGoogle Apps Scriptを準備してください。設定後、アプリの「設定」タブでGAS WebアプリのURLを入力すると連携が有効になります。

## データの取り扱い

被験者プロフィール・食事記録・血管年齢の計測値は、いずれも利用者のブラウザ内（localStorage）にのみ保存されます。同じURLを複数人で利用しても、各利用者の記録が他人と混ざったり、外部のサーバーに送信されたりすることはありません（LINE連携を設定した場合を除く。その場合は連携先のGoogle スプレッドシートにデータが蓄積されます）。

## 注意事項

本アプリは研究・実証実験用のプロトタイプです。血管年齢やベジチェック値の表示・メッセージは医療的な診断や助言を目的としたものではありません。実際の健康状態については、必要に応じて医療専門家にご相談ください。
